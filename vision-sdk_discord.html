Discord Bot

Discord bot integration ​

shell
cd services/discord-bot

Configure .env

shell
cp .env .env.local

Edit the credentials in .env.local.

Run the bot

shell
pnpm -F @proj-airi/discord-bot start

TIP

For @antfu/ni users, you can

shell
nr -F @proj-airi/discord-bot dev
